# Issue Tracker
Issues for this repository are tracked in **GitHub Issues**.

## Workflow
- Use the `gh` CLI to create, list, or interact with issues.
- **IMPORTANT**: Because this is a fork, all `gh` commands must explicitly target the fork with `--repo Maniyagupta/MedRemind` (e.g., `gh issue create --repo Maniyagupta/MedRemind`). Never target `PrRj06/MedRemind`.
- Skills like `to-tickets` will use `gh issue create --repo Maniyagupta/MedRemind`.
- PRs are the primary interface for proposing changes.
