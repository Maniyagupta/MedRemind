# Triage Labels
The following labels are used to manage the triage workflow:

- `needs-triage`: New issues requiring initial review.
- `needs-info`: Issues that require more context or clarification from the reporter.
- `ready-for-agent`: Issues that are actionable by an AI agent.
- `ready-for-human`: Issues that require human intervention or complex decision-making.
- `wontfix`: Issues that have been reviewed and determined to be out of scope or unfixable.
